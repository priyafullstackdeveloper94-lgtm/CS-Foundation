
# CS Foundation

CS Foundation is an educational platform designed for Tamil Nadu State Board 11th and 12th Computer Science students.

## Features

* Home Page
* About Page
* 11th Standard Computer Science Chapters
* 12th Standard Computer Science Chapters
* Chapter-wise Navigation
* Summary Notes
* 2 Mark Questions
* 3 Mark Questions
* 5 Mark Questions
* MCQ Practice (In Progress)
* Coding Practice (In Progress)

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Future Enhancements

* Dynamic Content Loading using JSON
* Fetch API Integration
* MCQ Quiz System
* Coding Practice Section
* Student Progress Tracking
